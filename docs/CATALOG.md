# Источники каталога и настоящие загрузки

Каталог содержит 128 приложений (28 прежних и ровно 100 добавленных пакетов
Android) и 15 браузерных игр. `backend/data/seed.json` — данные первоначального
наполнения и обновления SQLite, а не клиентский модуль каталога. В работающем
приложении записи получает API из базы `catalog.db`.

Сто добавленных приложений взяты из официального репозитория
[F-Droid](https://f-droid.org/), а не созданы как демонстрационные карточки.
Описание, название, версия, размер APK и оригинальная иконка извлекаются из
официального [индекса](https://f-droid.org/repo/index-v2.json). Отсутствующие
оценки, число установок и имена авторов обозначены как неизвестные. Для APK
выбирается стабильная версия с предпочитаемой репозиторием подписью и поддержкой
ARM64 или универсальная сборка.

`docs/catalog-sources.json` хранит выбранные 100 package ID, SHA-256 индекса,
исходный URL, лицензию, размер и SHA-256 каждого APK, отпечаток опубликованной
подписи, требования к Android, ABI и SHA-256 иконки. Иконки скачаны в
`public/media/<package-id>/` и сверены с контрольными суммами индекса. Данные
индекса проверяются по размеру и SHA-256 из `entry.json`, полученного по HTTPS;
скрипт не выполняет проверку JAR-подписи самого индекса.

В `downloadsByPlatform` различаются два источника:

- `file`: настоящий APK или EXE из официального репозитория либо от издателя.
- `store`: официальная страница Google Play, если издатель распространяет
  приложение через магазин. Переход к магазину не выдается за скачанный APK.

Сайт не переупаковывает чужие приложения и не подменяет их установщики своим
EXE. Файлы загружаются из указанного официального источника. Установка Android
APK требует совместимого устройства и разрешения установки из выбранного
браузера; Windows не устанавливает APK как обычный EXE.

## Обновление и проверка

```sh
# Первое получение / последующее обновление официального индекса и 100 записей.
node scripts/import-fdroid.mjs --refresh

# Повторный импорт из проверенного локального кеша .runtime/catalog-import.
node scripts/import-fdroid.mjs

# Проверка количества, уникальности ID, источников и всех локальных иконок.
node scripts/verify-catalog.mjs

# Проверка всех URL и полных контрольных сумм трех небольших настоящих APK.
node scripts/verify-catalog.mjs --remote --sample-apk

# Дополнительно записать результаты проверки HTTP в provenance JSON.
node scripts/verify-catalog.mjs --remote --record
```

Официальные API F-Droid описаны в
[документации репозитория](https://f-droid.org/en/docs/All_our_APIs/).
Список добавляемых ID задаётся данными `docs/catalog-sources.json`, поэтому
обновление не требует размещать карточки приложений в TypeScript.
Старый `scripts/export-seed.mjs` теперь только проверяет seed и не перезаписывает
его из устаревших клиентских данных.
